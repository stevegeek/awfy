## Notes

awfy is a benchmarking tool I wanted for my own gems. The idea was mine; the
plan was worked out with an AI; the implementation has been the AI's
throughout, under my direction. I have run it and skimmed the code rather
than read it line by line, so the level is `skimmed`, and the reviews and the
tests are the AI's work.

It is still an alpha, which is why I make no recommendation either way. I
have set it aside since late 2025: I do not use it myself and no one maintains
it. I may return to it, but I am not sure.
